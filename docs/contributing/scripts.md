# Contributor scripts

Run from the repository root. See [Contributing](../../CONTRIBUTING.md) for setup
and [testing](testing.md) for requirements. Paths below are relative to `scripts/`.

| Path | Purpose |
| --- | --- |
| `quality-matrix` | Supported-runtime checks, then latest-runtime performance |
| `test-quality-matrix` | Orchestration tests using simulated containers and Mix commands |
| `check-performance` | Benchmarks with CI's VM settings |
| `performance-regression.exs` | Guarded workloads and fixed-baseline comparisons |
| `benchmarks/` | Focused rendering/image benchmarks |
| `fixtures/` | Browser sheets and PNG/PDF cases |
| `data/` | HTML entities, quotation data and licenses |
| `examples/` | Documented HTML/PDF examples |

## Common commands

| Task | Command |
| --- | --- |
| Full matrix, serial runtime lanes | `./scripts/quality-matrix` |
| Optional concurrent runtime lanes | `QUALITY_MATRIX_JOBS=2 ./scripts/quality-matrix` |
| Validate/print runtime config without Docker | `./scripts/quality-matrix --matrix-json` |
| Performance | `mise exec -- ./scripts/check-performance` |
| Browser parity telemetry | `MIX_ENV=test mise exec -- mix run --no-start scripts/browser-parity-report.exs <evidence-directory>` |
| Browser sheet equivalence | `MIX_ENV=test mise exec -- mix run scripts/fixtures/check-browser-sheet-equivalence.exs` |
| Browser page equivalence | `MIX_ENV=test mise exec -- mix run scripts/fixtures/check-browser-page-equivalence.exs` |
| Browser sheets | `MIX_ENV=test mise exec -- mix run scripts/fixtures/build-browser-sheets.exs` |
| CFF font corpus and Type 2 reference vectors | `python scripts/fixtures/build-cff-fonts.py` with fontTools 4.66.1 |
| CFF standard character mappings | `python scripts/data/build-cff-mappings.py` with fontTools 4.66.1, then `mise exec -- mix format lib/html_to_pdf/font/cff_data.ex` |
| HTML/PDF examples | `mise exec -- mix run scripts/examples/generate-html-to-pdf.exs` |

Raise `QUALITY_MATRIX_JOBS` for additional runtimes only when resources allow.

## Variable-font and WOFF2 references

The two six-glyph “Authored Variable” faces in `test/fixtures/fonts/` are the
source artwork for `variable-fonts.json` and `variable-cff2-fonts.json`.
The original binaries are in commit `229a20f77a77f4bf8af51eb66fec703b080fba59`
at those same paths. Each manifest pins the corresponding source SHA-256.
To edit the artwork in TTX, preserve its bounding boxes and timestamps:

```sh
fonts=test/fixtures/fonts
out=tmp/font-references
mkdir -p "$out"
for face in selected-variable.ttf selected-variable-cff2.otf; do
  ttx -q -o "$out/$face.ttx" "$fonts/$face"
  ttx -q -b --no-recalc-timestamp -o "$out/$face" "$out/$face.ttx"
  cmp "$fonts/$face" "$out/$face"
done
```

Use fontTools 4.66.1 and Brotli 1.2.0. The following command regenerates both
instance manifests, the three WOFF2 encodings in `woff2-fonts.json`, and their
reference manifest. It samples four weight/width coordinates, reads serialized
TrueType points and metrics, and records CFF2 pen commands at the original
fractional blend coordinates.

```sh
python scripts/fixtures/build-font-references.py "$out/generated"
for file in "$out"/generated/*; do cmp "$file" "$fonts/${file##*/}" || exit 1; done
```

The transformed and literal WOFF2 files use the DejaVu Sans and Mono subsets
from `build-font-containers.py`. The CFF encoding uses the Sans derivative
from `build-cff-fonts.py`. Keep `selected-container-LICENSE.txt` with these
fixtures. The three “Authored WOFF2 Edges” inputs in `woff2-edge-fonts.json`
are separate originals from the same commit. That manifest pins their encoded
hashes, decoded table hashes and glyph geometry. The test corpus builds the
multi-face wrappers from the registered inputs at suite startup.

## Regeneration rules

| Concern | Rule |
| --- | --- |
| Prerequisites | Read the generator header for required inputs and tools |
| Reference inputs | Review regenerated bytes and retain provenance |
| Performance identity | Keep workload IDs, logical input keys, hashes and guard membership; `input_sources` records current paths |
| Moved inputs | Moving a file never resets reduction, timing or size baselines |
| Temporary work | Experiments in `tmp/`; validation evidence in `.quality/` |
| Script names | Use the operation and feature |
